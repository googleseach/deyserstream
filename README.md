# Deyser.Stream

Plataforma de streaming de videojuegos con una página de inicio general y dos secciones inspiradas en los diseños de **Blood Strike** y **GTA VI**.

## Estructura del proyecto


## Cómo empezar

1. Abre `index.html` en tu navegador para ver la página de inicio.
2. Modifica los archivos CSS y HTML de cada página para replicar el diseño deseado.
3. Añade las imágenes correspondientes en las carpetas `images/bloodstrike` y `images/gtavi`.
4. Sube el proyecto a GitHub cuando estés listo.
